# Godfred Nsiah – Portfolio

**Live site:** https://godfred-nsiah.github.io

One business, followed from market research to automated CRM workflows:

1. **Market research:** competitive landscape of 13 prepaid carriers in Thüringen (Tableau)
2. **Campaigns:** ROI and conversion across 12 campaigns and 96 partners (Tableau)
3. **Sales funnel:** 198 approached shops → 91 active partners (46%) (Tableau)
4. **Retention:** churn-risk scoring and a weekly visit list (Tableau)
5. **CRM & automation:** HubSpot pipeline with weighted forecast. Make calls the HubSpot REST API, logs new onboarding deals to Google Sheets, emails a checklist, skips deals it has already processed, and sends an alert if the API call fails
6. **Recommendations:** five next steps based on the findings

**Tools:** Tableau · HubSpot · Make · REST API · Google Sheets · R

All data is simulated for portfolio purposes. It is based on realistic scenarios from my work as a zone manager and does not represent real company data.
